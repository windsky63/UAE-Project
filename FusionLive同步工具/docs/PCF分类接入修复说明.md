# PCF分类接入修复（2026-10-28）

旧后台分析直接从PCF模型生成焊口行，遗漏独立PCF入口中的单元上下文和材料实例唯一码准备步骤。依赖元件连接关系的规则因此可能不生效，大量焊口保留默认S-F000预制分类。

修复后，PCF焊口生成前先调用 `apply_model_unit_context` 和 `assign_material_unique_codes`。单元沿用已核对的管线/原文件单元归属；同一根管子在不同焊口共用实例码，同目录材料代码的不同元件分配不同实例码。材料目录代码不能直接代替实例码。分类入口检查必需身份字段，缺失时明确报错而非静默采用默认预制结果。

原始260818规则脚本、阈值及几何计算未改动。真实PCF回归样本验证：斜管两端触发S-F006安装分类；同规格两只弯头的实例码不同；归档目录中的单元可传入无单元标记的管线；设备安装口规则仍正常生效。

此修复会改变分类结果，解析缓存版本已升级。后台重新处理本地候选文件，不会重新下载原件或删除台账，也不会把旧版缺少身份字段的已分类缓存用于新汇总。重算完成前，焊口表及简报可能只包含新版本已经完成的部分。

升级后安全启动后台解析，查看 `runtime/file_analysis/progress.log` 和 `exports/焊口表.csv`。抽查“单元号”“材料唯一码1/2”“分类规则”“分类引擎”，并结合源PCF核对变化。缺少材料信息或无法识别单元的源文件仍需核对，不能承诺每个焊口都有完整源数据。

修复前29,605道焊口的样本预制率为95.86%（按寸口量）；该比例不是修复后的计算结果。真实比例必须由服务器原始PCF重算后确认，不能仅修改CSV标签或重新导出旧缓存。

版本：2026.10.29-stop-recovery.1

将更新包内容覆盖到实际运行的 FusionLive同步工具 目录。
卡住时可先覆盖更新包，再双击“紧急停止.cmd”；它使用新代码定位旧进程。
已运行进程不会因覆盖文件更新代码，停止后需要重新启动。

立即中断：
双击工具根目录“紧急停止.cmd”，或在该目录运行：
python main.py scheduler --force-stop
仅结束本目录打开 sync.lock / scheduler.lock 且命令匹配本工具的 Python 进程。
无法读取进程信息时不猜测PID，不结束全部Python进程。
平台注销可能未确认；注销看门狗不在强制结束范围内。
紧急停止写入 runtime/login.paused；核实平台会话已退出后，手动删除此文件以恢复平台自动登录。
保留锁文件；文件存在不等于被占用，删除锁文件不能结束线程。
若仍显示后台分析或微信投递未退出，应按提示继续检查；紧急停止不强杀这些任务。

修复内容：
1. 安全退出命令等待120秒后明确返回失败，保留停止请求和现场；不自动强杀下载进程。
2. 下载收尾先保存任务状态和日报。发现停止请求时，不再启动全量临时文件遍历和完整Excel台账导出。
   完整台账可稍后通过离线导出生成；已开始的数据库或文件操作仍需完成。
3. 注销异常、范围待确认、同步完整性检查失败不再关闭离线简报调度。
   同步异常退出暂停后续自动登录；凭据获取或同步启动异常也保留离线调度。
4. 定时简报子进程独立刷新当天下载日报，不再完全依赖当天是否执行过下载。
   日报刷新失败仍继续尝试管道简报。
5. 停止等待超过30秒，下载子进程向 runtime/sync-stop-stack.log 记录调用栈。
   尚未启动完成的调度子进程不会清除完整退出请求并继续下载。
6. 离线简报子进程终止等待10秒，超时才强制结束该离线进程并限时等待。

定时规则：
北京时间02:00—10:30内启动下载；超出时段打开工具会等待下一次窗口。
默认10:40准备简报、11:00推送，可按设置调整；错过当天窗口不会自动补发旧简报。
盘点或关联核对未完成、范围未确认、runtime/login.paused存在时，也不会自动下载。

当前环境不存在后一个目录，未结束该现场进程，也未取得它的线程堆栈。

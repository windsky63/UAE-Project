# 简报文件数量与PCF/IDF合并

## 单线图PDF文件数

按PDF文件自身的施工图编号识别：52地上新建、53碰口、54拆除、58地下承压管道单线图。支持下载文件的 `__rev_版本__文件ID__指纹` 后缀。13-61单线图目录、伴热单线图及分配站图、电气图和45类土建图不计入管道ISO。

只统计当前有效且本地已完成下载的散装文件，以及已展开包内实际发现的文件路径。不能用目录名称或平台ISO标签认定附件，也不预估未展开压缩包内的文件数；缺失、下载未完成的本地文件不计入。未识别的文件保留在文件数量明细中。数字区域0—5的施工编号按H0—H5及三位单元归属，其他不明确区域沿用已核对归属或保留未知。

这里统计的是PDF文件数，不读取PDF正文、不计算页数，不以PDF文件数代替图纸页数或管线数。同内容的不同有效文件路径仍作为文件计数，历史修订由下载台账的active状态排除。

## PCF/IDF动态展示

- 只发现PCF：显示PCF文件数、PCF管线数和PCF解析焊接量。
- 只发现IDF：显示IDF文件数、IDF管线数和IDF解析焊接量。
- 两者都有：显示PCF/IDF文件数、PCF/IDF管线数和PCF/IDF解析焊接量。

名称按本次简报总体的数据来源确定，主表及单元表使用一致名称。文件数相加，例如2个PCF加3个IDF为5个文件；管线和焊接量则先按“项目、单元、管线号”去重。同管线两种格式都有效时采用PCF，IDF补充未重叠管线；PCF冲突但IDF有效时采用IDF。不同项目或单元中相同管线名不会合并。

重复来源列在“PCF-IDF合并核对”工作表。原“统计依据”“解析焊口明细”继续保留各格式原始结果，不能直接用原明细行数代替合并焊口数。不同格式出现数量差异时，应按明细核对原始文件。

只有分组汇总而没有逐管线明细、且同单元存在两种格式时，不直接相加可能重叠的数量，显示待核对。失败和冲突管线排除，未知口径和未分类焊口不按0估算，继续保留有效小计。

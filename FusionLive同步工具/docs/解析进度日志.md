# 解析进度日志

手动打开 `maintenance/解析本地管道文件.cmd`、正式下载自动拉起的后台解析，以及管理中心启动的解析任务，均实时输出进度。进度逐行立即刷新，不等待输出缓冲。

统一持久日志：`runtime/file_analysis/progress.log`，UTF-8，追加保存。每行带北京时间（+08:00）和进程 PID。自动后台进程原有 `worker.log` 也保留控制台输出和异常堆栈。手动窗口的正常进度会同时写入 progress.log；更新前已启动的旧进程须安全退出后重启才有新日志。

日志包含启动与实际台账/缓存路径、解析缓存版本、扫描开始及候选统计、已完成缓存/待解析/处理中/失败数量、当前文件与字节数、尝试次数、解压开始与完成、包内逐条进度、PCF/IDF 元件解析、焊口生成与预制/安装/未分类小计、结果文件路径、耗时、失败原因及重试说明、停止和退出。

阻塞操作每 30 秒输出当前处理阶段和累计耗时。这是进程存活提示，不是完成百分比，也不能保证第三方解析器没有阻塞。空闲时每 30 秒说明正在等待新文件或失败重试。扫描状态无变化时不反复打印完成统计；扫描逐候选耗时较长时每约 5 秒报告已扫描数量。任务统计仅含当前有效源文件任务；ZIP 任务数、包内文件数和管线数分别标记，不能混作同一进度分母。

已完成且兼容的缓存会明确显示为可复用，不会为了增加日志重新解析。此版只增加可观测性，保留上一版解析缓存键。PCF 预制/安装分类及简报结构沿用上一版。

PowerShell 实时查看（先进入工具目录）：

```powershell
Get-Content -LiteralPath .\runtime\file_analysis\progress.log -Encoding UTF8 -Tail 60 -Wait
```

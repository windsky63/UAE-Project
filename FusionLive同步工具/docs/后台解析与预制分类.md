# 后台解析设置及 PCF 预制/安装算法

管理中心 → FusionLive 同步 → 配置设置 → 后台解析，可设置：

| 设置 | 默认值 | 用途 |
|---|---:|---|
| 新文件扫描间隔 | 5秒 | 每轮扫描完成后，再等待该时间检查台账 |
| 空闲状态提示间隔 | 30秒 | 没有可执行任务时的日志提示频率 |
| 手动启动空闲退出时间 | 0秒 | 管理中心“恢复后台解析”及普通 --watch 启动；0表示持续等待 |
| 自动启动空闲退出时间 | 120秒 | 下载/简报自动拉起的解析进程空闲退出时间；0表示持续等待 |

设置保存在原同步配置 runtime/wechat_push.json 中，与推送字段共存，不另建主台账。保存后安全停止当前后台解析并重启以应用。CLI的 --poll-seconds、--idle-log-seconds、--idle-exit 可覆盖本次启动设置，自动启动也使用所保存的扫描和提示间隔。区间为0.1—86400秒，退出时间可为0。

## PCF 分类变更

PCF 的几何元件和焊口仍由现有解析器生成；预制/安装分类改为以下两步：

1. 内置 equipment_reader.py，来源为根目录 PCF焊缝信息读取v5.py。提取设备连接、设备/虚线法兰和虚线异径管的安装口坐标；仅适配函数输入输出，取消硬编码目录和Excel写出。
2. 内置 prefab_rules_260818.py，完整保留用户提供的预制率提高算法260818.py。适配器用当前焊口表和前一步设备连接数据替代Excel输入，按原有顺序执行分类规则，跳过最终Excel和统计表写出。规则原有的小管径、材料识别模式以及停用规则保持脚本默认设置，不额外启用被原脚本停用的规则。

多管线 PCF 先按明确管线边界分段，再独立运行设备提取和规则，防止不同管线之间串联。坐标按原文件单位转为毫米，设备口径换算为DN。根目录两个原始脚本不修改；运行仅依赖同步工具 app 下的内置文件。

原 WELD-LOCATION/WELD-ATTRIBUTE3 不再决定 PCF 的预制/安装结果，仅保留为审计信息。报告 analysis.json 中每个焊口保留分类引擎版本、最终规则编号及规则执行轨迹。算法异常会记为解析失败，不回退到旧分类、不伪造成功。螺纹连接继续按原统计口径排除，IDF 保持原分类口径。

焊口明细同步写入工具目录 `exports/焊口表.csv`（UTF-8 BOM，可直接用 Excel 打开）。后台解析每批队列处理完毕、正常停止时，以及简报读取缓存汇总时更新；直接执行本地解析也会导出，无台账的独立样本分析写入指定输出目录下的 `exports`。表内包含项目、单元、来源格式、原文件、焊口号、口径、两侧材料及唯一码、数量、坐标、最终 S/F 类型、分类规则、引擎版本、原始位置标记及规则执行轨迹。PCF 和 IDF 通过来源格式区分，IDF 不套用 PCF 算法。

导出使用与统计小计相同的去重明细，有版本冲突的管线不计入。尚有待解析、失败或不可用文件时，表内“汇总状态”标为部分结果；无有效焊口时仍输出表头，清除旧表中的过期明细。单个文件的后台任务只写自己的缓存，统一汇总后再替换导出表。

算法、适配器及设备提取代码加入缓存版本指纹。升级后旧版本结果不会计入新版汇总，重新发现时自动排队；不删除主下载台账、下载文件或旧结果。重解析完成前简报只显示新版已有结果，应等待队列处理完成再核对完整小计。新增依赖 pandas、numpy，已加入 requirements 和含环境部署包。

# ima 知识库管理

管理中心内的知识库管理页面与无界面命令行工具。默认使用本目录的 `待同步`，资料提取只复制副本，原文件与原压缩包保留。

## 首次使用

1. 打开项目根目录的 `打开管理中心.cmd`，选择左侧“ima 知识库”。本目录的旧启动文件也会转到管理中心，不再打开 Tk 桌面窗口。
2. 在服务器安装项目根目录共享依赖；管理中心通过共享 `.venv-analysis` 启动无界面 ima 任务。
3. 凭证已配置时无需再次填写；需要更换时，在凭证区域填写 Client ID 和 API Key，点击“加密保存凭证”。可从 <https://ima.qq.com/agent-interface> 登录获取凭证，注意重新获取可能使旧 Key 失效。
4. 设置待同步、下载数据库和下载原目录，点击“读取知识库”选择目标并保存配置。在“云端内容”读取目录，必要时选择“设为同步目标”后保存。
5. 点击“提取本地资料”或勾选“同步前提取数据库资料”。原文件在服务器上时，请在服务器运行。
6. 点击“扫描本地文件”检查资料，再点击“预览上传计划”，结果显示在“最近上传计划”页签。预览不复制实际资料，也不上传云端。
7. 核对目标后点击“手动同步”，确认弹窗后由后台任务执行一次。入库成功表示接口已接受，文档解析可能仍在进行。
8. “允许自动同步”默认开启以兼容旧配置；点击“启动自动同步”后，按北京时间每日定时执行，默认 13:00，可在同步配置中修改。一天最多同步一次（含手动同步），执行前持久记录次数，重启不重复执行；到点未运行时，启动后补执行当天一次。关闭网页不会终止后台任务。
9. 仅需手动同步时，关闭“允许自动同步”并点击“保存 ima 配置”。运行中的自动任务将在当前文件或请求完成后安全退出；待状态显示“未启动”后点击“手动同步”。关闭状态持久保存在 `runtime/settings.json` 的 `auto_sync_enabled`，管理中心启动入口（含全部启动）和命令行 watch 均会拒绝自动同步。手动同步仍使用已保存的配置，可照常在同步前提取数据库资料，但计入当天一次的同步次数。
10. 重新开启开关并保存不会直接启动任务，需点击“启动自动同步”。“安全停止”仅停止当前任务；其他配置变更仍需安全停止后重启才能应用。

手动同步和自动同步共用单实例锁及安全停止请求；关闭自动同步开关时仍可启动手动同步，点击安全停止会在当前文件或请求结束后退出。不会因为手动任务不属于自动监控而忽略停止请求。

管理中心 ima 页面按用途分为四个入口：

- **同步工作区**：按“提取本地资料 → 预览上传计划 → 执行同步”操作，下方直接查看上传计划、本地文件和提取结果。自动同步的启动、停止位于工作区底部。
- **云端内容**：选择知识库、读取目录和搜索内容；“设为同步目标”会转到配置页，保存后才生效。
- **任务与记录**：分别查看后台任务、上传回执和每日记录，失败任务可直接打开对应日志。提交任务不代表执行成功；预览失败时明确提示下方可能保留上次结果。
- **同步配置**：集中设置目标、三个本地路径、提取开关、自动同步及凭证。未保存的修改会标记出来，并阻止按未保存配置发起提取、预览和同步。

上传计划、本地文件、提取结果、云端列表、后台任务、上传记录、每日记录均支持分页；可切换每页 20、50、100 条，并按关键词筛选，适用记录还支持状态筛选。计划通过本地记录接口读取完整结果，不再截断在前 500 项；上传回执不再限于最近 200 条。后台任务和每日记录同样可查询完整历史。日志弹窗按每页 20 条显示现有运行日志接口可用的输出。

自动同步每轮记录资料提取、生成计划、执行同步等阶段。单个文件提取失败会输出具体原因并继续处理其他文件；一轮发生文件、接口或 SQLite 异常时，记录失败并等待次日定时执行，不在当天重新开启一轮；等待期间仍可安全停止。入库结果待核对的文件继续遵守回执保护，不会直接重复入库。手动单次任务仍通过非零退出码报告失败。

若日志末尾出现 `ima HTTP 403`，先看新版日志中的接口名称和业务错误原因。实际验证中，`check_repeated_names` 在连续逐文件请求时会返回 HTTP 403、业务码 `200001`、`请求频率超限，请稍后重试`；这种情况不能解释成凭证错误。预览现按官方支持的每批最多 2000 个文件检查重名，只对需要检查的文件发起请求；未变化、待核对、已归档等文件继续使用原回执保护。每批返回必须完整且文件名唯一匹配，结果缺失或异常时仍停止，不跳过重名检查。上传前仍重新检查单个文件，防止预览之后云端出现同名文件。

所有正式 OpenAPI 请求按账号共享节流状态（`runtime/api-rate.sqlite3`）：普通请求至少间隔 1 秒，同一账号的重名检查至少间隔 3 秒。这里是本工具采用的保守间隔，不是官方限额声明；预览仍按目录批量查重，上传前仍复查文件名，不能跳过重名保护。

每次等待后都会重新检查共享冷却与请求间隔，只有当前可以发送时才领取名额，避免其他进程新增限流冷却后旧排队请求仍然发出。自定义 HTTP 会话和实验诊断入口也遵守同一个节流器；同一部署的 CLI、管理中心与定时任务不会各自独立放行。该状态只协调当前部署，不能控制其他机器或其他应用对同一账号的请求。

每收到一次明确的 `200001`、`110021` 或 HTTP 429 限流响应，本轮运行的普通请求和重名检查间隔都再增加 0.5 秒（例如 1/3 秒 → 1.5/3.5 秒 → 2/4 秒）。增量只保存在内存，本轮成功请求不会清零；程序重启、新客户端或常驻定时任务下一轮同步开始时，从基础 1/3 秒重新开始，旧版数据库中的自适应增量不再读取或更新。跨进程基础限频、已放行请求的短期时间间隔和服务端 Retry-After 冷却仍保留，重启不绕过有效冷却。普通权限拒绝、网络错误和额度码 220021 不触发加时。

接口收到明确的 `200001` 或 `110021` 限流响应时，最多尝试三次，重试前分别至少等待 30、60 秒；服务端的 `Retry-After` 更长时按其要求退避，冷却状态共享给其他进程。超过 5 分钟的冷却不阻塞当前任务，而是报告冷却并结束本轮。持续限流会中止本轮同步，不再逐文件继续请求；保留已成功回执及中止报告。`220021` 仍等待 5、10 秒确认，连续三次返回该码后中止。普通权限拒绝不作为限流重试，写入请求遇到网络超时或无法确认结果的 HTTP 错误仍不自动重发。CLI 的节流和退避等待响应安全停止。错误保留接口名、业务码和经凭证脱敏的原因。

目录读取按计划和执行阶段分别缓存，不再每上传一个文件就重新遍历相同目录。批量查重无重名时，不为普通新增文件读取整份目标目录；根目录新增上传可以不调用 `get_knowledge_list`。执行时每个本地同步根的范围检查只做一次，同一路径的目录身份在一轮中复用，新建目录直接复用已验证的目录ID。预览与执行不共用缓存，避免执行沿用旧目录身份。移动和重命名前仍实时读取身份，写入成功或响应丢失后使受影响的目录缓存失效，必要的移动、归档结果核验保持有效。已耗尽的目录读取额度不会因更新程序立即恢复；新目录定位或旧版归档仍可能需要等待ima额度恢复。

下次允许启动同步时，同一账号、知识库、目录、路径和内容指纹已有成功回执的文件跳过；普通失败文件重新尝试。已明确返回 `200001` 或 `220021` 的入库拒绝保留为可重试回执；网络中断等结果不确定的入库仍需人工核对，避免重复。这里是按文件恢复，不是从 PDF 文件的某个字节继续上传。一天最多一次的同步规则仍然有效，失败后不自动释放当天次数；请保留 `runtime/state.sqlite3`，不要通过删除回执或每日次数数据库重试。

如接口返回的确为凭证或权限拒绝，再在服务器管理中心核对 ima Client ID / API Key，使用“读取知识库”核对可添加内容的知识库，选择目标并保存。若读取知识库成功而读取目标目录失败，还需核对目标知识库及文件夹标识和访问权限。修改配置或凭证后安全停止并重启自动同步。

## 从同步工具数据库直接提取项目管理规定与图纸

默认只读同级 `FusionLive同步工具/runtime/ledger.sqlite3`，不读取、生成或刷新 Excel。每轮按数据库登记的文件身份、业务分类和路径映射，提取下载原目录中实际存在的资料，因此不受 XLSX 快照过期影响。“下载原目录”默认为 `FusionLive同步工具/downloads`；原文件在服务器上时，应在服务器运行。

管理中心“同步配置”中的“下载数据库路径”对应 `database_path`，可指定实际服务器数据库。旧配置没有该字段时，自动按已保存下载目录的同级 `runtime/ledger.sqlite3` 推导，读取配置时不擅自写回文件。正常流程点击“提取本地资料”或勾选“同步前提取数据库资料”，无需先导出台账，也不需要 ima 凭证。

数据库以 SQLite `mode=ro` 和 `query_only` 打开，不创建、迁移或修改下载数据库。读取当前已提交快照后及时关闭连接；WAL 模式下不会把尚未提交的路径变化用于提取。文件身份由“工作区 + 内容ID”确定；按同一身份的 `local_paths.local_path`、`files.path` 和 `files.target_path` 查找实际文件。普通文件保留下载时的 `-2`、`-3` 等区分后缀，不按后缀大小选择所谓最新版。

以下载原目录中实际存在的文件为准，不要求其为平台最新版本或关联仍有效。新版尚未下载时，可提取仍留在下载原目录的旧版；新版尚无路径或文件尚未落盘时直接跳过，不记为提取错误。文件替换、移动及归档由同步工具管理，ima 不移动或修改下载原件，始终排除下载原目录外的 `history`、`runtime/download_ready` 等历史和暂存文件。筛选范围仍为全部专业 PP 正文与已确认分类的 PDF 图纸，不按同名文件猜选缺失身份。

业务分类复用同步工具已确认的编码规则，文件自身编号优先，不以目录名或标题猜测专业。压缩包成员复用已有、已提交并与本地父包版本匹配的索引，包括仍在下载原目录的旧版父包，直接从原 ZIP 读取副本；支持包内路径中的嵌套 ZIP，最多 8 层，每层成员不超过 200 MiB。不重新解析或修改原压缩包，不自动解压非 ZIP 压缩包。父包在读取快照后变化时跳过不匹配成员。

副本仍存放在 `待同步/项目管理规定/01～07 分类/文件名`，07 下不增加专业子目录。报告标明数据来源、工作区、内容 ID、实际来源和目标，界面以内容 ID 区分同名记录。读取快照后文件被移动或删除等提取异常会显示具体 ID 及登记路径；不改选其他身份的同名文件，不读取下载目录外的路径。上述本地文件筛选用于默认数据库模式；旧 XLSX 兼容入口仍按表内记录核验路径。

图纸副本存放在同一个知识库根目录的 `待同步/图纸/业务类型/厂区/单元/文件名`，与“项目管理规定”并列。点击现有“提取本地资料”，以及同步前的自动提取，均会同时处理两类资料，无需新增配置。例如：

```text
待同步/
├─ 项目管理规定/01_项目管理/PP-…pdf
└─ 图纸/
   ├─ 地上新建管道单线图/H2_Habshan 2/单元233/…pdf
   ├─ 地下承压管道单线图/H4_Habshan 4/单元262/…pdf
   ├─ 地上_地下碰口管道单线图/H4_Habshan 4/单元262/…pdf
   ├─ 主体钢结构标准图/GG_跨厂区通用/单元000/…pdf
   ├─ 工艺管道及仪表流程图/H4_Habshan 4/单元113/…pdf
   └─ 图纸/厂区或单元无法确认的文件.pdf
```

图纸仅提取 PDF（扩展名大小写均可），不提取 DWG、DXF、PCF、SHA、图片、表格或整个压缩包。分类目录使用已确认编码规则中相应的图纸业务类型，包含台账现有的其他图纸类型；类型名里的 `/` 等目录保留字符替换为 `_`，不增加额外层级。文件自身编号须能确认该图纸类型；仅从关联文档继承分类的附件、ATR/CC 校审附件、WTRAN 传递单及未识别业务类型不作为图纸提取。

同一目标分类目录中的同名文件按 SHA-256 核对：内容相同只保留一份，其他来源记录为 `unchanged`；内容不同保留现有文件，并使用 `原文件名-1.pdf`、`原文件名-2.pdf` 等最小可用编号。已有编号文件内容相同时直接复用；已被占用的编号不覆盖。编号只区分副本身份，不表示版本新旧。后续提取复用已登记的编号。

`runtime/collection-report.json` 保存本轮来源与目标；`runtime/collection-state.json` 持续保存每个来源的 `source_identity`、`identity_tag`（如 `-1`）、原文件名、源路径（含 ZIP 成员路径）、工作区、内容 ID、压缩包内容 ID、SHA-256、原目标路径与实际目标路径。相同内容的多个来源分别登记，可追溯到同一副本。请保留这些状态文件。提取时逐条提交到 `runtime/collection-pending.sqlite3`，结束时才一次汇总 JSON；进程中断后自动恢复已提交记录。复制时同步计算哈希，避免为计算哈希再次读取整个临时文件。

厂区和单元同样只按文件自身编号划分：厂区使用编码规则确认的“编码_名称”（GG 为“GG_跨厂区通用”），单元使用“单元+原编号”，保留前导零及已确认的既有两位原编号。单元名称未列入单元表不影响已确认编号的归档。若厂区或单元任一项缺失、厂区编码未确认，或同一文件包含多个厂区/单元编号，PDF 直接放到对应业务类型目录中，不建“待核对”目录，不用关联文档、原下载目录或压缩包标题补猜。暂不增加 CWA、系统、设备或修订号层级。本规则对后续提取生效，已生成的旧平铺副本不自动迁移或删除。

源内容变化且旧副本仍与该来源的提取回执匹配、且没有被其他来源复用时，校验旧副本后原子替换为新版，已分配的编号保持不变，不保存本地历史旧版。每次正式提取还会清理工具此前生成的 `待同步/删除/更新旧版` 专用目录；预览不清理，手动移入“删除”其他目录的文件保留。手工修改、没有匹配回执或被其他来源复用的不同内容保留原副本，新内容分配编号。缺失的正常副本仍可重新提取；源下载文件与源 ZIP 始终只读。NAS 上传与 ima 提取可同时只读打开原件；遇到 Windows 独占占用时，ima 等待 1 秒、2 秒重试读取，持续占用则记录失败并保留原副本，次日再试。复制期间源文件变化、被替换或移动时不发布该新版。

单条提取失败或冲突保留在报告并设置 `has_issues`，其余记录继续处理。任务正常收尾返回 0，页面提示“已完成，有提取问题”，可继续预览和同步可用文件。实际上传失败或入库结果待核对仍返回非零。数据库本身不可读、路径配置不安全或提取回执损坏等任务级异常仍如实报告。

在 `Ima知识库管理` 目录可独立运行：

```powershell
python -m ima_manager collect --database '..\FusionLive同步工具\runtime\ledger.sqlite3' --downloads '..\FusionLive同步工具\downloads' --dry-run
python -m ima_manager collect --database '..\FusionLive同步工具\runtime\ledger.sqlite3' --downloads '..\FusionLive同步工具\downloads'
```

`plan/sync/watch` 同样支持 `--database`；`--no-collect` 只跳过本轮提取。`--database` 与 `--ledger` 互斥。只有显式传入 `--ledger 文件台账.xlsx` 才使用旧 Excel 快照兼容模式；设置文件里遗留的 `ledger_path` 不会自动启用它。兼容模式仍优先从“完整字段”取得身份，默认工作流程不再依赖 Excel。


## 每日更新 TXT

待同步根目录维护一个 UTF-8 文件 `每日更新记录.txt`，由复制、上传和归档流程自动追加。每条一行，包含北京时间、操作、文件相对路径、结果，内容变化时附前后版本 SHA-256 的前 12 位；云端操作还包含知识库/目标目录，失败或冲突附简短原因。

示例：`2026-11-03 16:30:00 | 云端更新 | 项目管理规定/a.pdf | 成功 | 版本=旧摘要→新摘要 | 目标=知识库/根目录`。新增复制、本地副本更新、上传、云端更新、本地/云端逻辑删除及任务失败都会记录；未变化文件不逐条重复写，连续相同结果合并，恢复成功后再次失败仍保留，跨天重新记录。预览操作不写业务更新记录。

该 TXT 不参与上传，也不能通过本地逻辑删除按钮移走；隐藏的 `.ima-state/journal.sqlite3` 只用于合并连续重复记录。管理中心按记录分页显示历史，完整 TXT 同时保留在根目录。清理管理中心 `.log` 不会删除它。

## 文件同步规则

- 默认源目录为 `Ima知识库管理/待同步`，也可手动选择其他目录。这里没有自动选用已整理的 1.8 GB ZIP 或全部项目文档。
- 勾选“包含子目录”会递归扫描，所有文件**平铺到选定的同一个云端目录**，不自动重建云端目录树。本地不同子目录出现同名文件时会拦截，请选择更具体的源目录或先改名。
- 支持 PDF、Word、PPT、Excel、CSV、Markdown、TXT、PNG/JPEG/WebP、XMind、HTML、EPUB。按官方大小限制预检，图片额外校验真实文件签名。此版本未启用音频上传，因为还需要可靠校验两小时的时长限制。
- ZIP、视频、未知类型、空文件、超限文件会显示“已拦截”。扫描忽略隐藏文件、Office 临时文件和链接目录，不读取源目录外的链接目标。
- 已成功上传且内容 SHA-256 未变化的本地文件按账号、知识库、文件夹和本地路径分别记录，后续自动跳过。
- 同路径、同名文件内容改变时，若云端有唯一匹配本工具旧版上传回执的同名条目，会自动更新并归档旧版。没有唯一回执或存在多个同名条目时仍报告冲突。自动同步不做永久删除或权限修改。
- 直接从磁盘删除文件不会影响云端；需要逻辑删除时，将文件移入同步目录内的“删除”子目录。成功记录是本机上传回执，不是云端实时镜像；若用户在云端删除过资料，本机仍可能显示“已同步”。
- 多个本机上传任务通过 SQLite 进程锁互斥，防止 GUI 与命令行同时上传。来自其他电脑/客户端的并发同名写入仍由服务端行为决定，无法保证原子去重。
- 正式写入不做盲目自动重试。若最终入库请求超时、响应缺失，或进程在入库中途退出，会保留“待人工核对”状态，避免重复入库。

## 云端操作范围

自动同步按待同步内的文件生成任务，不把云端目录当作需要全量清理的镜像。云端手工创建而本地没有对应项的目录、文件保持原状。例如，本地 `项目管理规定` 只有 `01` 到 `07`，云端额外的 `08` 不会被遍历或作为写入目标；云端额外的 `项目.csv` 不会被移动、改名或替换。

实验管理按钮也执行相同限制：源文件必须同时有本地同名文件和同账号、知识库的媒体 ID 上传回执；目标目录必须对应本地目录；创建云端目录前，本地必须已经存在对应目录。单独在云端改名成一个本地不存在的新名称同样被拒绝。没有回执的云端同名手工文件也不会被自动接管。

执行前会重新检查本地文件及云端旧版名称，防止预览后文件已被移除或改名仍继续修改。工具自身为更新和归档维护的 `更新暂存`、`删除/更新旧版` 目录仍用于存放有明确本地来源和回执的版本，不对其中其他用户文件进行清理。

## 同名文件的更新过程

例如今天上传 `a.pdf`，明天同步工具在原路径下载了内容不同的新 `a.pdf`：

1. 数据库提取校验本地旧副本后，直接将正常位置的副本原子替换为新版，不再保留本地 `待同步/删除/更新旧版/...`。原下载文件只读。
2. 上传计划显示“待更新”。只有同一账号、同一云端目标、同一本地路径的旧上传回执与当前唯一云端同名条目匹配时才会自动替换。
3. 新版先上传到当前云端同步目标的 `更新暂存/任务目录`，核验该条目存在。这个核验不代表服务端已完成文档解析。
4. 确认新版入库后，将旧版移入云端 `删除/更新旧版/版本目录`，保留原文件名。再把新版移到正常目录，正常目录最终只保留新版。
5. 新版上传失败时，旧版仍留在正常目录。若旧版归档或新版发布阶段中断，会保存更新任务并在下次同步继续核对，旧版文件仍保存在删除目录中，不会被永久删除。
6. 更新成功后，重复同步跳过未变化的新版。旧版可由用户在 ima 中手动清理。不同文件名或不同本地路径的文件仍按独立文件处理，不凭相似文件名猜测版本关系。

这些更新状态与上传回执保存在 `runtime/state.sqlite3`。新版暂存入库结果不明确时，先按媒体 ID 重新读取目录；仍无法确认则显示“待人工核对”，可用已有“处理待核对”入口处理，不会盲目重传。

## 本地“删除”目录的逻辑删除

默认位置为 `Ima知识库管理/待同步/删除`。将文件从正常同步位置**移动**至这里，就作为逻辑删除；也可在工具的“本地文件与同步计划”页选中文件，点击“移入删除目录”。选择其他同步源目录时，工具同样建立其 `删除` 子目录。

例如原文件 `待同步/资料/a.pdf` 应移至 `待同步/删除/资料/a.pdf`，保留相对路径。这个目录中的文件不会作为新增文件上传，即使开启递归或自动同步也一样。

预览和执行规则：

- 仅移入本地删除目录时，界面显示“本地已逻辑删除”，文件内容仍保留在磁盘。
- 若同一账号和同步目标有原路径、相同 SHA-256 内容的成功上传回执，计划显示“待逻辑删除”。执行同步时，会把该媒体 ID 对应的云端文件移入**当前云端同步目标目录下**的 `删除` 子目录，必要时创建该目录。
- 移动后核验源目录中不再存在该媒体 ID，且删除目录中存在，才显示“已逻辑删除”。最终清理由用户在 ima 客户端处理。这个功能使用此前实测的未文档化移动/建目录接口，不调用永久删除接口。
- 找不到匹配的成功上传回执时，仅保留本地逻辑删除状态，不根据文件名猜测云端对象。复制进删除目录但原位置仍保留文件时会拦截。文件内容变更后与回执不一致也不会自动移动云端旧文件。
- 本地删除目录已有同路径文件时拒绝覆盖。云端删除目录内已有同名文件时，在删除目录下创建按媒体身份区分的子目录，保留旧归档和原文件名。
- 移动响应中断时保留目标位置，下次同步先检查是否已移入，避免重复操作。重新同步已逻辑删除文件不会再次上传或移动。
- 将文件移回本地原位置不会自动恢复云端文件；云端恢复需在 ima 中手动完成。已手工移动到其他云端目录的文件，也需要先核对位置再处理。

## 入库结果待人工核对

在 ima 客户端按文件名查找，并参考“任务记录”的媒体 ID。确认是否入库后，在预览计划中选中待核对的文件，点击“处理待核对”：

- “是”：确认已经入库，记为成功。
- “否”：确认没有入库，允许下一次重新上传。
- “取消”：保留待核对状态。

这是对本机回执的人工处理，不执行云端删除。若 COS 上传成功但后续入库失败，可能留下没有关联到知识库的对象；此版本不会擅自清理它。

## 凭证与本机数据

凭证通过 Windows DPAPI 加密，保存在 `runtime/credentials.dat`，只能由当前 Windows 用户在可解密的环境中使用。不要将该文件作为可移植配置分发。普通设置中不保存 API Key。

用户明确要求携带凭证的私有部署包可通过 `build_deployment.py --overlay --include-ima-credentials` 生成。包内 `credentials.bootstrap.json` 含可迁移明文凭证；服务器首次读取时加密到该服务器用户的 `runtime/credentials.dat` 并删除迁移文件。已有加密凭证优先保留，成功读取后也删除迁移文件；环境变量配置优先级最高。请私下传输和保存含凭证的 ZIP，解压目录中的自动删除不会移除 ZIP 内的原始内容。

也可使用环境变量，优先于本机加密文件：

```powershell
$env:IMA_OPENAPI_CLIENTID = '你的 Client ID'
$env:IMA_OPENAPI_APIKEY = '你的 API Key'
```

两个值必须一起设置。兼容 `IMA_CLIENT_ID` / `IMA_API_KEY` 变量名。接口凭证仅发给 `ima.qq.com`；COS 上传仅使用服务端临时凭证，禁止跟随上传重定向。日志与回执不保存凭证或 COS 签名。

`runtime/settings.json` 保存源目录和选定目标；`runtime/state.sqlite3` 保存上传回执；`runtime/latest-plan.json` 保存最近扫描计划。它们包含本地路径等私人元数据，已忽略 Git 提交。`待同步` 内的实验资料同样被忽略。

## 命令行

从本工具目录运行，下例 `python` 可替换为 `..\.venv-analysis\Scripts\python.exe`：

```powershell
python -m ima_manager configure

```

GUI 保存的源目录和目标会作为命令行默认值；显式传 `--source`、`--kb`、`--folder` 可覆盖。`--folder ''` 表示根目录，`--top-only` 表示只扫描源目录顶层。ID 必须来自服务端响应，不能从网页地址猜测。

不确定记录也可在人工核对后解锁：

```powershell
python -m ima_manager resolve --kb '真实ID' --path '本地文件绝对路径' --outcome uploaded --execute
# 确认未入库才使用 --outcome absent
```

`watch` 持续运行时，Ctrl+C 请求停止；不需要模型或 Agent 消耗。

### 2026-11-04：按相对目录同步

预览和执行均按本地相对目录逐层匹配所选云端目录。例如，所选目标为知识库根目录时，`待同步/项目管理规定/02_质量管理/a.pdf` 对应云端 `项目管理规定/02_质量管理/a.pdf`。若所选目标已是云端“项目管理规定”，则以对应本地子树为基准，不再重复创建一层“项目管理规定”；其他本地子树会标记为不在当前目标范围。

预览显示云端目标路径并读取对应目录中的文件，不创建目录或上传。缺少的目录仅在执行同步时创建；路径存在重名文件夹或文件占用时停止该文件的同步。不同目录可有同名文件。旧版平铺计划必须重新生成。

“云端已存在”表示同一目标路径已有文件，但缺少本工具的匹配成功回执，尚未验证内容；跳过上传和覆盖，不能据此认定内容完全相同。“内容未变”仍仅依据同一真实目标目录、同一本地路径和内容哈希的成功回执。只有具备唯一旧版回执的文件才执行版本更新。更新、逻辑删除和人工核对均使用文件实际所在的云端父目录。旧版平铺在根目录的文件和回执不会被当作子目录里的文件或自动迁移。

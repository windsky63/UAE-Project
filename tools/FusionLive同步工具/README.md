# FusionLive同步工具

本工具负责平台盘点、下载、目录维护和下载台账。下载成功收尾后生成推送文。解析、简报和微信发送已归资料解析及管理工具，本目录不保留这些功能的模块、设置、启动或恢复入口。

## 快速开始

[项目说明](../../README.md) · [管理中心](../../管理中心/README.md)。优先在管理中心的同步工具页面配置与运行，也可使用下方独立 CMD。

1. 先运行项目根目录 `安装依赖.cmd`，所有工具共用根目录 `.venv-analysis`。
2. 在管理中心核对平台登录、项目范围、下载及调度设置；已有本地设置继续保留。
3. 启动下载调度，查看本轮任务与日志。启动前离线检查通过，只表示环境和程序具备启动条件，不代表平台登录或下载成功。
4. 下载后在文件台账中核对状态及本机实体文件。台账导出只读取现有数据，不补下载缺失资料。
5. 修改设置或部署更新前先安全退出，等待当前任务收尾和注销完成。

## 独立入口

- 启动正式下载.cmd：离线检查后启动下载调度。
- 安全退出.cmd：请求下载安全收尾与注销。
- 紧急停止.cmd：仅用于无法正常收尾时的人工紧急操作。
- 打开文件台账.cmd：查看本机下载台账。
- 整理文件目录.cmd：目录维护。
- maintenance：依赖安装、完整性检查及盘点维护入口。
- devtools：仍在使用的下载诊断、编码参考和统计预览脚本。
- docs：下载文档及历史记录；历史路径以当前入口为准。

业务数据和实际配置仍保留在runtime、downloads、history等既有位置。微信恢复入口在codex-wechat和资料解析及管理工具根目录。

项目部署统一使用管理中心/tools/build_deployment.py；本工具旧版补丁打包脚本已删除。

文件台账导出归本工具：管理中心同步工具的任务操作区点击“导出文件台账”，或运行 `python main.py ledger_export`。导出读取已有台账，不启动下载或登录平台。


## 命令行与数据

在本工具目录运行，共享解释器路径为 `..\..\.venv-analysis\Scripts\python.exe`：

```powershell
# 查看命令参数，不启动业务
& '..\..\.venv-analysis\Scripts\python.exe' main.py scheduler --help
# 从已有台账导出，不登录平台
& '..\..\.venv-analysis\Scripts\python.exe' main.py ledger_export
```

`runtime/ledger.sqlite3` 是下载台账，`downloads` 保存正式资料，`history` 保存历史版本，`exports` 保存导出。NAS、ima、解析和微信问答会使用台账或实体资料；不要单独搬移下载文件或清空 runtime，以免失去路径映射和恢复状态。

`app` 为业务实现，`maintenance` 为维护入口，`devtools` 为开发诊断，`tests` 为离线回归。历史 docs 中旧路径以本说明和当前管理中心为准。

## 常见问题

- 程序完整性不通过：确认已完整覆盖同一部署包及清单；不要只复制 main.py。
- 台账登记但资料不可读：核对下载结果、本机路径和实体文件，导出 Excel 不能替代原件。
- 安全退出等待较久：查看当前下载或注销日志；紧急停止只在无法安全收尾时人工使用。
- 需要简报或恢复微信发送：进入资料解析及管理工具或 codex-wechat，本工具已移除对应模块。

## 开发验证

从项目根目录运行统一入口，先查看本组件测试计划：

```powershell
& '.\.venv-analysis\Scripts\python.exe' '管理中心/tools/run_tests.py' --full --component sync --plan
```

去掉 `--plan` 才执行测试，详见 [测试约定](../../管理中心/TESTING.md)。

## 运行日志

独立运行日志保存在 `logs/YYYY-MM-DD/sync/`，调度为 `scheduler.log`、下载为 `run.log`、桌面工具为 `gui.log`、注销守护为 `watchdog.log`。进度默认每 30 秒汇总，空闲提示默认每 300 秒；异常和阶段变化立即记录。日志按北京时间切日，每文件 5 MiB，保留 4 份轮转副本。受管理时使用中心日志服务和配置，主进程输出由中心保存，不重复落盘；业务 CSV/JSON 审计继续保留。

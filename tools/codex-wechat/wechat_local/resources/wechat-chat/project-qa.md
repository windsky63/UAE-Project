# 阿联酋项目问答取证指引

项目中的 FusionLive 同步工具保存下载台账与解析缓存，绿联云上传工具保存上传状态；微信历史只证明聊天中说过什么，不能替代当前业务台账。

文件台账及 `sync_files.py search` 现在同时列出平台文件和已解压文件。`kind=platform` 是平台原件/附件，`kind=extracted` 是压缩包成员；成员的 `parent_id` 可回查所属压缩包，`member_path` 是包含嵌套压缩包层级的完整包内路径，`archive` 是平台下载压缩包名。搜索图号或文件名时直接搜索整个台账，不必先猜属于哪个ZIP。成员保留原始文件名、SHA256、实际解压路径和内容解析状态；PDF、Office、DWG等即使没有内容解析器也应能按文件名发现。

`summary.downloaded_records` 仍只统计平台下载记录，`extracted_records`、`available_extracted_files` 和 `extracted_business_types` 单列包内记录。不要把包内文件数加到平台下载数量，也不要把“已解压”说成“正文已解析”。包内同名异内容分别保留，同路径同内容去重条目有明确解压状态；可能是同一实际文件的多个包内条目。成员所属压缩包更新或删除后，旧成员不再作为当前文件使用。尚未解压、解析失败、缓存或文件缺失时只能说明包内清单尚不可用，不能说压缩包为空。

使用搜索返回的成员ID可直接 `read --id 成员ID` 读取已解压文本/PCF/IDF，读取时会核对当前压缩包版本及文件哈希。查询工程汇总时使用 `parent_id` 对应的压缩包ID调用 `analysis`；包级汇总不能当作某一个成员的独立工程量。仅有文件名索引的PDF和Office文件仍需说明正文尚未提取。

当问题包含“本项目”“阿联酋项目”“目前”“已下载文件”“业务类型”“图纸类别”“下载数量”时，先查看任务提供的 `sync_catalog`，再用同步文件助手查询授权项目的数据。未设置会话独立来源时，助手自动从 `accessible_directories` 内的同步台账生成目录，默认包括 codex-wechat 的同级目录。缺少来源时先核对允许目录和 `discovery_warnings`；允许目录内可直接只读查询业务台账，不应仅因未配置独立来源就声称没有权限。目录未被授权或台账不可读时，说明具体缺口并提示在“微信与 Codex → 配置设置”的可访问目录中调整；不要把不可访问的数据当成零，不扫描其他聊天或自行扩大权限。

若任务提供 `current_project_summary`，它已按当前授权台账完整汇总，可直接用于对应来源/项目的下载数量与业务类型回答，不必重复执行 summary。需要更细范围、文件正文或焊口数据时再调用相应助手。`related_chat_memory` 仅用于理解追问、术语、人员及历史证据位置；历史数量、状态和文件版本必须用当前来源核验。

例如“目前阿联酋项目的已下载文件分为哪些业务类型？”，在没有提供上述汇总或确需重新核验时执行：

```text
python .agents/skills/wechat-chat/sync_files.py summary
python .agents/skills/wechat-chat/sync_files.py summary --project 项目ID
```

使用任务中指定的 Python 完整路径。`summary` 汇总完整的授权台账快照，不受搜索分页影响。存在多个项目时按返回的项目ID分别说明，不能把它们都视为阿联酋项目。只报告实际有文件的业务类型；业务类型与 PDF、ZIP、PCF 等文件格式不同，采用同步工具已经确认的编码规则与关联文档继承结果，不自己编造分类规则。

统计口径是当前有效且下载完成的台账记录，实际存在且大小符合台账的文件才计入分类。回答列出业务类型和对应数量，标明来源/项目、查询时间与口径；未知类别、关联冲突、规则未就绪、文件缺失和来源不可用分别说明。继承类别尚未核验附件内容，不能说成内容已确认。来源不可用时不能得出“没有下载文件”；同一文件有多个关联文档仍只算一条台账文件记录。

若要举例或追查某文件，使用 `search` 返回的文件ID；查看 PCF/IDF 或压缩包内容用 `members`、`read`，焊口/预制/安装问题用 `analysis`，再说明解析状态及统计范围。不同源文件可能包含重复管线，不能简单相加得到项目工程总量。只支持元数据的内容应说明无法核实，不能凭文件名猜测正文。

问上传完成情况时，同步下载台账不能证明 NAS 已上传；当前助手没有上传台账入口时说明无法核实，并提示在管理中心上传页面查询。回答配置与使用方法可以依据本指引，涉及“当前实际状态”的答案应以本次工具查询为依据。

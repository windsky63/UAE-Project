图纸变更简报复用管道简报的 Excel/PNG 排版。双击“生成图纸变更简报.cmd”，或运行：

简报仅用一张汇总表：负责范围按当前台账存在的单元及专业逐行展示（含零变更行），其余归为“其他单元和专业”一行，“未识别”单独一行。无项目列和单独的负责范围说明行。

第三列“文件数”为当前本地台账中有效图纸的总数，包括当日未变更图纸，按项目及图号去重；不含失效、明确非最新和取消的图纸。“删除/不可见”沿用不可见事件口径，不表示已确认删除。变更列统计指定日期的事件，文件数统计生成时的当前库存，不是历史日末快照。

    python main.py drawing_briefing --date 2026-11-14
    python main.py drawing_briefing --demo --date 2026-11-14

输出在 logs/日期/图纸变更简报；模拟示例使用独立目录。仅离线读取，不发送消息。

微信发布复用原有简报调度、会话名单和发送时间。正式 briefing 命令同时生成管道和图纸两类图片，存入带日期的管道简报不可变版本目录及统一发布清单。会话发布设置增加 publish_drawings（默认不勾选），与 publish_text/publish_briefing 独立；全局 publish_drawings 控制图纸发布。未选择图纸简报的群不发送图纸图片。图纸图片的投递编号从10001开始，不随管道页数变化。管理中心每日推送页支持仅推送图纸简报，手动发送沿用已保存会话配置及哈希校验、投递去重、不确定结果拦截。独立 drawing_briefing 命令仅生成预览，不直接发送。

负责范围统一保存在管理中心/config/drawing_scope.json，Ima 和图纸简报共用管理中心的 drawing_scope.py 读取及校验。可在下载工具的配置设置或 Ima 的同步配置中编辑“图纸负责范围”，保存时防止覆盖其他窗口的修改。每次生成简报和后续 Ima 归类均重新读取。配置缺失或无效会报错，不静默改用空范围。单元不限定厂区，兼容两位及三位单元号。

配置格式如下，已移除原独立配置及命令行覆盖入口：

```json
{"disciplines":["管道","钢结构","安全、消防及火气设备"],"units":["027","037","038","039","213","265","273"]}
```

须同时匹配专业与单元才归入负责范围。无法识别专业或单元的图纸单列待识别。模拟示例也使用共享配置的当前负责范围。

统计当日北京日期内的文档和文件变更事件，按项目及图号去重；关联附件的变更归入图纸。仅统计编码识别为图类或平台 documentType 为 ISO/DWG/DRAWING 的记录，不把所有 PDF 当作图纸。重复事件不重复计数，同一图纸可同时属于新增和更新。Excel 附图号、当前版本及变更类型明细。

更新包括平台元数据变化，不表示图面内容已对比；不可见不代表删除。图号、版本和分类使用当前台账字段，历史事件不提供旧版图面差异；本地未记录的事件不纳入统计。

# 资料解析及管理工具

负责本地资料解析、管道日报、图纸日报及其发布。推送文由同步工具在每轮下载成功收尾后生成，本工具不生成推送文。

管理中心提供独立的解析工具页面和启停入口。现有下载数据、台账、解析缓存及发布记录保留原路径，无需搬迁。

## 首次使用与数据目录

[项目说明](../../README.md) · [管理中心](../../管理中心/README.md) · [解析文档](docs/README.md)。项目内使用时，先运行根目录 `安装依赖.cmd`，在管理中心解析工具页面核对数据来源及发布设置，再启动后台解析或生成日报。

本工具程序目录与业务数据目录可以不同。`--data-home` 指向包含 `runtime/ledger.sqlite3`、`downloads` 等数据的目录；项目内通常是同级 `FusionLive同步工具`。不指定时默认使用本工具目录，也可由 `PROJECT_DATA_HOME` 指定。选错目录可能读到空台账或找不到原文件。

`material_split_rules.json` 是解析工具的程序资源，始终从本工具目录读取，不随 `--data-home` 改变。队列的解析版本指纹使用实际加载的材料规则和编码规则；同步工具目录无需放置材料拆分规则。

下面命令从本工具目录执行，`python` 在项目内应替换为 `..\..\.venv-analysis\Scripts\python.exe`。`D:/项目数据` 是占位路径，须改成实际数据目录。独立部署时先安装本目录 requirements.txt。

## 常用命令

常驻 scheduler 会按保存的配置执行解析、发布及图纸发送；不是只读检查。briefing 生成日报，是否发布应先核对发布配置。运行正式命令前可先用对应命令的 `--help` 查看选项。

```powershell
python main.py scheduler --data-home "D:/项目数据"
python main.py scheduler --stop --data-home "D:/项目数据"
python main.py briefing --data-home "D:/项目数据"
python main.py analysis_worker --watch --resume --data-home "D:/项目数据"
```

管理中心设置 PROJECT_MANAGER_HOME 后，微信发送使用中心 shared_services；独立运行使用内置 wechat_push。管理模式绑定失败会报错，不静默回退。同步工具不再保留解析命令或转发入口。

全局范围在“配置设置 → 图纸负责范围”中统一保存，负责专业、负责单元和具体图纸类型均用开关选择，三者同时匹配才属于负责范围。Ima 归类、图纸简报和图纸文件发送共用类型限制；关闭的类型仍可归入其他图纸并统计。定时发送区域不重复设置全局具体类型，默认沿用负责专业和单元，也可单独用开关缩小或指定发送专业、单元。

全局和群聊弹窗复用同一个负责范围组件，包含专业、单元、业务图纸类型、文件格式四组开关，默认折叠；完整列表包含已选和未选项。“全部开启”和“全部关闭”须弹窗确认。文件格式默认仅 PDF，可在全局开启 DWG、DXF；群聊只能在全局允许范围内进一步限制单元、专业、业务类型和文件格式。开启单独设置时复制全局已选项，取消编辑不修改已保存配置。

“定时发送图纸文件 → 图纸接收群聊”列表只显示摘要，点击编辑后在弹窗中填写群名、开启单独负责范围，并用开关选择本群专业与具体类型。类型选项受全局负责类型及所选专业限制，单元沿用全局发送单元；取消弹窗不保留草稿，保存群聊设置直接保存配置。未开启专业、单元或类型时不发送。旧版重复的发送全局类型限制会转换为群聊类型限制，避免扩大既有发送范围。

首次启用、新增群聊或修改发送范围后的首次检查，仅为当前匹配文件建立基线，之后发送新增或更新文件。范围修改不会补发该范围内已有的全部图纸；既有发送和待核对记录保留。调度在后续检查时重新读取这些设置。


## 独立入口与运行管理

“单元资料推送文”由本解析工具独立生成，读取图纸负责范围中的单元列表，分别统计 PCF、PDF、SHA。累计数量取当前有效且下载完成的文件，含已登记的压缩包成员；相同输出路径去重。今日更新按北京时间下载日期，包内文件沿用所属压缩包日期。此统计只使用负责单元，不受图纸发送的 PDF 格式开关影响。

单元资料推送文已并入“资料解析及管理设置”和原有发布流程，使用共享的推送会话名单，每个会话勾选“单元资料推送文”后接收此内容；同一设置区域配置其发送时间。不提供独立配置卡片或定时启用开关，也不再读取旧的 `runtime/unit_text.json`。原有发布控制器统一调度下载日报、单元资料推送文及简报，停止解析调度会统一收尾。手动生成入口在“运行管理”；“每日推送”卡片显示快照、正文和发送按钮。正文与防重记录仍分别保存，避免混淆不同内容；同一会话每天提交一次，结果不确定不自动重发。

命令行生成：`python main.py unit_text --data-home "D:/项目数据"`。每日推送页面分别显示原下载日报、单元资料推送文、管道简报和图纸简报四张卡片。

- `解析本地管道文件.cmd`：本地管道解析入口。
- `生成管道简报.cmd`：管道简报入口。
- `生成图纸变更简报.cmd`：图纸变更简报入口。
- `恢复微信发送.cmd`：兼容清理旧版暂停标记；当前紧急快捷键只中断本次操作，后续发送无需手动恢复。

这些 CMD 使用 PATH 中的 `python`；若未激活共享环境，优先使用上文显式解释器命令，并传入正确的 `--data-home`。

在管理中心安全停止解析工具，或使用上文 `scheduler --stop` 请求收尾。发布配置变更后安全停止并重启。微信发送依赖实际登录的 Windows 桌面与兼容微信客户端，客户端提交成功不等于对方收到。

## 故障排查与开发验证

- 无可解析资料：先核对 data-home、下载完成状态、实体文件及压缩包成员是否就绪。
- 简报缺数据：检查解析队列和失败原因，不通过删除数据库强制重跑。
- 发布结果待核对：查看发布记录与微信实际历史，不直接重复发送。
- 旧 JSON 缓存：可按下文提前导入 SQLite，导入不重新解析、不发送微信。

从项目根目录查看回归计划：

```powershell
& '.\.venv-analysis\Scripts\python.exe' '管理中心/tools/run_tests.py' --full --component analysis --plan
```

去掉 `--plan` 才执行测试。业务台账、解析缓存及发送记录位于所选数据目录，备份和部署时应一并核对。

## 数据库存储与旧缓存转换

完整解析结果保存在 `runtime/file_analysis/queue.sqlite3` 的 `analysis_reports` 表，与任务状态在同一事务中提交。简报批量读取 SQLite；JSON 用作导出和审计，不再作为常规汇总的逐文件输入。

旧版结果可在部署后提前转换，避免第一次生成日报时才导入：

```powershell
python main.py import_result_cache --data-home "D:/阿联酋项目文件管理/tools/FusionLive同步工具"
```

转换只读取已生成的旧 JSON，不重新解析源文件、不发送微信，可重复执行。首次转换仍有磁盘开销。源文件存在、大小及身份检查保留；源文件、规则或任务状态变化会使汇总失效。每次生成均重新读取数据库并汇总，不复用上次总表。生成日志会分别记录源文件核对、数据库读取、旧结果导入和合并的进度与耗时。

此前存储迁移保留原解析算法与规则；`app/parser_compatibility.json` 保留对应部署版本的缓存身份。后续修改算法或规则仍会生成新的版本标识。


### 性能验证

本地 501 份小型模拟结果对照：旧 JSON 汇总约 6.95 秒，SQLite 批量汇总约 0.31 秒；汇总指标一致。该样本只用于验证存储开销，不能据此预测服务器上万份真实结果的耗时。记录见项目 `exports/snapshot_storage_benchmark.json`。

每次生成仍检查下载文件是否存在、大小和修改时间，以排除缺失或变化的源文件；不重新读取源文件内容。新解析结果与任务状态在同一事务写入，逐批读取时检查结果版本，避免并发更新被混作完整结果。旧 JSON 审计文件删除不会单独触发重新解析；解压产物失效仍按原规则恢复。


## 定时发送图纸原文件

管理中心 → 资料解析及管理工具 → 运行管理 → 定时发送图纸文件。设置聊天完整名称、北京时间并启用。首次启用或新增聊天自动建立现有图纸基线，不发送已有全部文件；之后每天只发送新增或更新的当前有效图纸。每个文件提交后附带业主平台修订号和文档版本 ID。

扫描范围为台账中识别为图纸的 PDF、DWG、DXF 原文件，要求下载完成、路径和SHA256有效。文件在发送前复制到临时目录并核对SHA256；当前版本有歧义时停止，不自行选取。每个聊天独立记录版本，文件内容相同但平台修订或版本 ID 改变也会发送。

记录位于数据目录 runtime/drawing_file_delivery.sqlite3。界面可刷新最近发送状态。文件已提交而版本消息失败、进程中断或结果不确定时，不自动重发，须人工核对。这里的“已提交”表示已提交微信客户端，不代表对方已收到。调度关闭会等待当前发送安全结束。

配置 runtime/drawing_file_delivery.json；默认关闭。独立部署可使用本目录 main.py scheduler --data-home 指定台账目录。


## 运行日志

独立日志位于数据目录 `logs/YYYY-MM-DD/analysis/`，主要查看 `analysis.log`、`analysis-worker.log`、`scheduler.log`；CLI 异常为 `cli-diagnostics.log`。受管理时使用中心日志服务及配置，主进程输出由中心捕获；后台解析独立保存日志。旧 `runtime/file_analysis/progress.log` 仍可读取，不再作为新版运行日志写入位置。简报输出目录的生成过程及 `runtime/publication_jobs` 子任务证据保留并限制单文件大小。默认进度 30 秒、空闲提示 300 秒，每文件 5 MiB / 4 份轮转副本，使用北京时间和 UTF-8。

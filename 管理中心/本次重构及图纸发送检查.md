## 检查发现与修复

1. 管理中心发送类未列入桌面保护子进程白名单：补齐白名单、管理中心绑定和导入路径，并用模拟子进程协议测试验证。
2. 管理中心 Codex 文件发送还在引用错误的相对 file_transfer 模块：改为正确的会话文件验证模块。
3. 改名拆分后部分内部调用与测试仍指向同步工具解析入口：改为新工具直接入口。
4. 解析工具独立部署依赖管理中心图纸范围模块：独立部署改读自身 runtime/drawing_scope.json；未配置时返回空范围。
5. Windows CLI 默认输出编码与管理中心读取编码不同：同步工具入口统一为 UTF-8。
6. 图纸定时线程若每30秒扫描全台账会增加无效磁盘开销：非发送时段且没有新聊天时直接返回；当天已检查也不重复扫描。
7. 完整解析结果已入数据库，删除审计 JSON 仍可能导致重解析：改为数据库存在有效结果时不因 JSON 缺失而重解析。
8. 解析工具曾携带下载工具本地凭据模块副本：移除该副本。

## 使用

管理中心 → 资料解析及管理工具 → 运行管理 → 定时发送图纸文件。填写聊天完整名称、北京时间，启用并保存，然后启动本工具调度。

发送配置、聊天基线及记录保留在现有数据目录 runtime 下，不移动已有下载文件或台账。重命名程序目录前应先停止旧解析任务；服务器升级时保留现有数据目录。

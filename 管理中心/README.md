# 本机工具管理中心

“ima 知识库”页面统一提供服务器凭证加密配置、台账复制、知识库选择与浏览、上传计划、单次/自动同步、旧版归档和人工核对。原 ima 启动文件会转到管理中心，不再启动独立桌面窗口。一键启动/安全关闭也包含 ima，启动确认中会说明资料上传及旧版归档行为。

ima 状态轮询只读本地配置、回执和任务记录；点击“读取知识库”或“读取当前目录”才连接 ima。配置使用原 `Ima知识库管理/runtime/settings.json`，密钥仅在服务器加密保存，不随状态接口回传。任务输出沿用项目统一日志目录，可在“运行日志”筛选 ima。

待同步根目录维护 `每日更新记录.txt`，按北京时间追加每份文件的新增、更新、逻辑删除及异常，包含相对路径、结果、短版本摘要、云端目标和必要原因；连续重复结果合并，结果变化和跨天事件保留。记录文件不参与上传，日志页面清理也不会删除该 TXT。

FusionLive 同步的“每日推送”页可按北京时间日期查看每日推送文、管道简报图片、Excel、定时调度状态、最近手动推送结果及逐会话投递明细。发送状态读取 `runtime/wechat_delivery/deliveries.sqlite3`，与生成状态分开展示；“已提交微信”仅表示客户端发送动作完成，不表示收到回执。若当前文件与已发送版本不同，会显示部分或旧版本已提交。

“手动推送”支持推送文、管道简报或两者，确认弹窗展示本次接收会话与内容，按已保存的全局和会话发布开关执行。仅支持当天已就绪的正式文件，可在自动推送时间窗口外补发；不重新生成文件，也不改变自动调度时间。复用原发送锁、校验和去重台账，跳过相同内容的已提交记录，不自动重发不确定结果或不同版本。后台任务的开始、结束和结果同时写入操作日志及该日管道简报目录的 `手动推送状态.json`。

工作台提供“一键启动所有工具”和“一键安全关闭所有工具”，均需确认后执行。启动使用各工具已保存的配置，跳过已经运行的工具；安全关闭沿用各工具的收尾流程，等待任务结束，不强制杀进程，管理中心保持运行。每个工具分别显示请求提交、跳过或提交失败的结果；实际执行结果见操作记录。

各工具“运行管理”页提供“清除操作记录”，确认后删除该工具已结束的管理中心任务记录及对应输出日志；运行中和待核对的记录保留。日志文件已被清理时仍可清除对应记录；文件删除失败会保留该条记录，并显示失败数量。此操作不删除工具运行日志、业务台账、配置、解析缓存或微信回复任务。

部署包和更新包统一写入打包工具所属目录的 `releases`：管理中心的完整包、离线包和更新包位于 `管理中心/releases`；FusionLive 独立更新包和微信推送测试包位于 `FusionLive同步工具/releases`。`exports` 保留业务导出数据，不作为部署包输出目录，打包时也不收集 `exports` 或已有的 `releases`。

“运行日志”页提供“清除日志”：按当前工具筛选清理，默认仅删除最后更新时间早于北京时间今天零点的日志，也可选择包含今天。清理范围涵盖管理中心任务输出、工具 logs 目录及运行时日志，只删除 `.log` 文件；不受日志级别、搜索词和分页影响。运行中的工具或后台解析日志会跳过，文件占用等失败会显示结果，可安全停止对应工具后再清理。台账、调度状态、解析缓存、会话、发送记录及生成的简报均保留；清理日志不会重置自动任务。

Codex CLI 0.164 兼容：对话使用命名权限配置，按平台设置读取范围并禁止自动提权，不再发送废弃的 readOnly.access/readOnlyAccess 字段。旧线程存档丢失时仅创建新的执行线程并提供有限的近期对话背景，不删除本地记录、不重发历史任务。微信首次配置默认开启回复/发送，数据库目录为D:/xwechat_files，账号为；空会话可启动为待配置模式，不读取数据库或调用Codex，保存会话后安全重启监听。已有配置明确保存的值保持不变。

同步配置页新增后台解析扫描间隔、空闲提示间隔、手动/自动启动空闲退出时间，保存后重启解析进程应用；CLI仍可覆盖本次启动。PCF预制/安装已改为内置设备连接v5与260818预制率算法，原PCF位置标签仅作审计，IDF保持原口径。算法更新会使旧缓存失效并自动重新排队，不需要删除下载台账。详见相邻同步工具 docs/后台解析与预制分类.md。

双击上一级目录的 `打开管理中心.cmd`，默认监听 `127.0.0.1:8765`。启动时自动打开带会话的浏览器页面。请保留管理中心窗口；关闭它会停止页面服务，已经启动的工具不会被强行结束。

局域网访问：先关闭已有管理中心服务窗口，再双击根目录的 `打开管理中心-局域网.cmd`，监听所有 IPv4 网卡。其他电脑直接访问 `http://服务器IP:8765/`，无需会话链接、Cookie 或主机名白名单；重启后地址不变，不再生成访问地址文件。局域网浏览器执行的下载、上传和 Codex 操作均发生在服务器上，仍共用同一套配置与会话记录。

如需固定配置，将 `network_config.example.json` 复制为 `network_config.json`，设置 `host`（`127.0.0.1` 为本机，`0.0.0.0` 为所有 IPv4 网卡，也可指定服务器网卡 IP）和 `port`（默认8765）。局域网模式不限制访问主机名，无需配置 allowed_hosts；该配置项仅用于本机模式。命令行 `--host`、`--port` 优先于配置，`--lan` 优先于 host 并启用所有网卡。修改后需重启服务，不能仅刷新页面。

若其他电脑连接超时，确认与服务器网络互通，并在服务器 Windows 防火墙允许对应 TCP 端口。可由管理员按实际端口执行以下规则（仅域/专用网络和本地子网，不自动修改防火墙）：

```powershell
New-NetFirewallRule -DisplayName "Project Tools LAN" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8765 -Profile Private,Domain -RemoteAddress LocalSubnet
```

局域网模式直接访问，不校验会话 Cookie 和 Host 白名单；浏览器写请求仍使用同源接口。本机模式继续使用本机会话链接。启动仅在窗口显示地址，不生成访问地址.txt。

启动入口使用纯 ASCII、Windows CRLF 换行，通过相邻的 `admin_launcher.py` 定位中文目录，避免 CMD 拆行或路径解码问题。这两个入口文件须放在三个工具和“管理中心”文件夹的共同上级目录；不要只复制 CMD。优先使用 `.venv-analysis`，没有该环境时尝试系统 `py -3` 和 `python`，要求 Python 3.11 或更新版本。管理服务自身使用标准库，业务工具仍需各自依赖。启动异常保存到 `管理中心/runtime/launcher.log`；缺少入口、Python 或前端文件时会给出明确提示。

管理对象为相邻目录的 FusionLive同步工具、绿联云上传工具和 codex-wechat。工具自行保持原有定时规则、登录方式、数据与运行锁。页面支持查看状态、启动/安全停止、检查、离线解析、生成简报、模拟全流程、配置、文件和日志。网页打开和刷新不会启动下载、访问 NAS 或发送微信。

- 工作台：当前运行状态、台账下载记录、后台解析状态和操作历史。本机缺少实体文件或解析缓存会如实显示未就绪。
- 同步工具：启动原调度器，或独立运行后台解析、简报生成。本地检查沿用原完整性和依赖检查，不登录平台。
- 上传工具：启动原上传调度，保持12:00—次日00:00规则。本地检查只验证完整性，不检查NAS连接。
- 微信与Codex：监听、停止、环境检查和模拟全流程；会话、项目文件来源与授权均使用原配置。
- 文件：展示全部当前有效文件（含待处理/失败），区分下载状态、后台处理状态及本机可读取情况。支持文件业务类型、专业、厂区/单元、编号、修订、日期、目录、大小、SHA256、识别依据等字段，显示列可自选，详情可查看全部字段；未下载或本机缺失文件不能预览/下载。

文件资料的每列标题可打开 Excel 风格筛选：同列多选按“或”，跨列组合按“且”，支持包含/不包含、等于、空白条件、字节数及日期范围和升降序。筛选、候选值计数和排序均覆盖全部记录，再进行分页；筛选值搜索仅定位选项，全选/全不选控制实际勾选。业务类型复用同步工具的已确认编码规则；文件编号优先，关联文档继承和冲突明确标记。分类实时派生，不要求重新下载、重解析或修改历史数据库。此更新同时为桌面文件台账和常规 CSV 导出补充业务类型字段。
- 日志：程序与测试输出统一使用 UTF-8（无 BOM）；启动时将可可靠识别的历史非 UTF-8 日志转为 UTF-8，原字节备份至 `runtime/log-encoding-backups`。无法恢复或仍在写入的文件保留原件并记录原因。查看历史日志不会要求用户修改文件。
- Codex 对话：左侧菜单位于“工作台”下方，与其他页面共用菜单、顶部栏和主题。主内容保留 Codex 风格的单栏对话、逐段回复、停止生成、历史恢复、命令与输出、文件记录和变更差异。可直接从左侧切换工具页面，未发送草稿和正在执行的对话会保留。

对话通过本机 Codex CLI 的 [App Server 协议](https://learn.chatgpt.com/docs/app-server)连接，沿用本机已登录的 Codex 账号，不在网页保存 API 密钥。模型留空时使用本机默认配置，也可在对话设置中填写模型名。默认“询问·只读”，切换“编辑·本项目”后允许修改本项目文件；权限在下一轮提交时生效。Windows elevated 沙箱要求根路径可读，因此 Windows 上允许读取项目外文件，写入仍受所选模式约束；其他平台保持限制读取范围。两种模式均禁用沙箱网络。对话不会自动批准提权请求；正式下载、NAS 上传和微信监听继续从对应管理页面启动。

“推理摘要”仅显示 Codex 提供的公开摘要，完整内部思维链不会存储或转发。文件记录依据工具的结构化读取、搜索、目录和变更事件；搜索范围与读取文件分别标记，未提供结构化路径的命令可在执行步骤中核对。对话和事件保存在本机 `runtime/codex-chat.sqlite3`，刷新恢复历史，事件流重连不会重发任务。关闭服务会终止其启动的 Codex App Server，重启后中断任务不会自动继续。

“微信与 Codex → 配置设置”保存共享连接方式与可访问目录。默认自动发现 codex-wechat 的全部同级目录，在页面显示完整路径；关闭“自动包含同级目录”后可手动增删，手动清空会保留为空。网页与微信共用此列表，微信只读，网页编辑模式仅对列表内目录添加写入权限。任务自身的聊天工作目录仍用于隔离存档和输出。该配置不会修复 Windows 文件夹本身的拒绝访问；Windows elevated 要求根路径可读，目录列表同时作为模型工作范围，不等于严格的操作系统读取隔离。

微信生成总时限默认 600 秒，消息回复有效期默认 900 秒，无进度时限默认 300 秒（0 为关闭，工具执行期间不触发，总时限仍有效）。默认开启“查询进度提示”和“@ 回复人”：开始执行工具时每条任务最多提示一次“正在查询……”，群聊最终回复使用微信原生 @ 提醒原提问人，私聊不 @。原生成员候选不唯一或选择器无法识别时保留未发送状态，任务表的“状态说明”显示原因。升级保留服务器原配置；已有 120/180 秒配置需在设置页调整为 600/900 秒，保存并安全重启监听。微信原生 @ 控件需在目标客户端版本实机验证。

“群聊摘要与问答记忆”默认开启，回复与短摘要在一次模型调用中生成；确认发送后维护该会话的 `data/chats/<哈希>/memory.md`。下次最多带入 3 条相关摘要，默认近期消息为 6 条、优先回复长度为 600 字符，均可在微信配置页调整。预先提供最新授权台账汇总，减少重复查询；历史数量、文件状态不能直接当作当前事实。每个会话的 `generation-metrics.json` 可查看最新生成耗时、工具调用次数和输入/输出用量，实际提速需在服务器实测。

微信默认使用常驻 App Server，每群/私聊复用各自的模型会话。默认 55% 上下文时后台预建空会话、70% 时完成当前回复后轮换，两项比例均可设置；切换时带入最新已确认问答摘要。比例使用最近一次上下文估计与报告窗口，供应商不报告时可手动填写窗口，缺少数据时默认每 20 轮保守轮换。重启或后端异常后重建会话并用本地记忆衔接；不会重放已经开始的生成。正常对话不再因满 32 轮而重启，仅在退役会话累积或清理异常时回收进程。连接配置缓存、只读权限、查询提示和 MD 摘要继续适用。指标文件记录上下文比例、会话复用/预建、创建耗时和切换时实际等待时间。旧 CLI 可选择 `exec` 兼容模式；此时不使用会话复用和预建。设置保存后安全重启监听。文件清单仍逐次构建当前授权快照。

网页模型设置默认“继承微信与 Codex 设置”；也可单独选择“跟随 Codex 默认”“尝试 WebSocket”“HTTPS 流式（跳过 WebSocket）”，单独选择只影响当前网页会话。共享配置保存后网页下一轮自动应用，运行中的微信监听需安全停止后重启。HTTPS 选项保留原模型服务地址与登录，不将自定义 HTTP 地址升级为 HTTPS；内置 OpenAI 使用独立命名配置，不覆盖全局 config.toml。Codex 可重试通知显示为“正在重连”，重试耗尽或任务终止仍显示失败信息。

微信群任务等待时发送带任务编号、回复对象及当时排队序号的“正在排队中……”；轮到处理时才发送开始时间及“正在思考中……”。查询提示带相同任务编号，正式回答带编号、回复对象、结束时间和“回答如下：”。时间统一为北京时间，发送重试沿用持久化时间。排队不消耗回复有效期，接收时仍过滤过旧消息；开始处理后计算生成和发送重试的有效期。提示分别去重，预览模式不发送。项目问答技能通过 `project-qa.md` 指导查询：未指定会话独立来源时自动从共享目录发现同步台账，指定来源时按其项目列表生成快照，来源根目录也须位于共享目录内。业务类型问题通过 `sync_files.py summary` 查询完整快照并复用同步工具分类规则，必要时可在允许目录内只读查询原始业务台账。

配置保存前校验，并通过内容版本标识避免覆盖其他窗口的修改。运行中的工具应先安全停止，再重新启动应用新配置。对于从命令行启动的工具，页面可通过运行锁识别，安全停止仍调用工具原有停止机制。关闭管理页面后仍在运行的任务在下次打开时标记待核对；实际运行锁和工具日志用于判断。

前端复用了桌面 `语言模型助手/legacy-system/web` 的 Vue/Vuetify 入口、主题、样式、ActionIcon、HelpTip 和 LogsPanel，并将接口改为当前三个本地工具。没有复制旧后端、账号、密钥、数据库或聊天记录。

开发：在 `web/` 执行 `npm run build`，由 `server.py` 提供构建后的 `web/dist`。已复用本机现有依赖。后端使用Python标准库，管理中心及全部工具统一使用根目录 `.venv-analysis`，根目录 `requirements.txt` 汇总依赖；配置校验、微信监听和独立启动入口均使用该环境。

网页与微信的 Codex 底层统一由 `codex-wechat/wechat_local/shared_backend.py` 管理，通过本机认证命名管道复用兼容配置下的一个 App Server 进程。入口之间按模型线程归属隔离消息与权限，微信仍只读；网页保留持久会话、不增加微信的预建轮换策略。共享后端最多同时生成2个任务，每个入口同时1个任务、最多64个已加载会话，连续空闲120秒或最后一个入口断开后释放进程。关闭一侧不会强杀另一侧仍在使用的后端。网页归档/删除会取消后台订阅，保留本地记录和持久线程存档。需要同时更新并安全重启网页管理中心与微信监听；旧进程不会自动切换新机制。

测试：从项目根目录执行 `.venv-analysis\Scripts\python.exe -m unittest discover -s 管理中心/tests`。浏览器QA使用Playwright；没有Browser插件时使用本机现有Chromium/Edge。验证只启动本地模拟与离线检查，不会运行正式下载、上传或微信发送。

需要保存测试日志时，使用 `.venv-analysis\Scripts\python.exe 管理中心/log_tools.py test --tool manager`（同步工具用 `--tool sync`）。该入口直接以 UTF-8 写文件；不要用 Windows PowerShell 的 `>`、`*>` 保存日志，它们的默认 UTF-16 编码不会受 `PYTHONUTF8` 影响。已有历史日志也可用同一脚本的 `normalize` 命令备份转换。

文件资料支持五个连续数字页码和指定页跳转。Codex 桌面布局默认显示左侧会话列表，手机通过历史按钮展开；每行右侧菜单支持重命名、归档、删除到回收站及恢复。操作仅整理管理中心会话记录，不删除项目文件或外部 Codex 线程；运行中的会话需先停止再归档/删除。已是空白会话时新建会复用它，模型设置统一从输入框底部模型按钮进入。
# 文件数量统计

首页与推送文统一读取 `FusionLive同步工具/logs/日期/日报快照.json`。快照同时保存正文、正式目录/历史目录数量及生成时间。文件总量=正式目录+历史目录，发送正文只取正式目录。首页和推送页取消15秒自动刷新；打开页面或手动刷新只读快照，不扫描目录或重新统计。

日报按配置的生成时间计算并保存快照，成功后当天不重复生成；未就绪时最多在发送时间补试一次。发送从当日快照取正文并先保存发送备份，失败重试复用备份。后台操作“生成日报快照”或 `sync push-report` 可显式更新快照；普通刷新只读取已有结果。

# 覆盖部署

在项目根目录运行 `.venv-analysis\Scripts\python.exe -B 管理中心/build_update.py`，生成 `管理中心/releases` 下的精简运行包。将 ZIP 复制到服务器，安全停止管理中心及后台任务，解压后将包内目录合并覆盖到原项目根目录，再从原入口启动。

默认包只包含运行程序、已构建网页、配置示例及运行时技能，不包含测试、开发工具、前端源码、开发记录或部署指南。服务器已有配置、登录文件、运行数据库和业务数据保留；无需使用 Codex 执行部署。开发源码及测试仍保留在本机。

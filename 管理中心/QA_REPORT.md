# 验证记录

本次复用既有界面，没有另行生成视觉方案。参考是用户指定的 legacy-system 的 Vue 组件、主题和样式，来源见 FRONTEND_PROVENANCE.md。

## 浏览器与视觉

Browser 插件不可用，因此使用 Playwright 与本机 Edge。已在1440×1100和390×844验证，使用view_image检查桌面工作台、微信配置页和手机页面截图。证据位于本机runtime/management-*.png及browser-qa.json（不随更新包分发）。

| 检查项 | 参考与实现 | 结果 |
|---|---|---|
| 导航结构 | 原248px侧栏、64px顶栏；业务导航替换为三个工具、文件和日志 | 保留原外壳 |
| 色彩 | 复用原蓝色主题、白色表面、浅灰工作区和蓝色选中项 | 一致 |
| 字体与控件 | 原Segoe UI/微软雅黑、Vuetify表单、图标与HelpTip/ActionIcon | 一致；明确加载图标尺寸，消除SVG负尺寸错误 |
| 设置 | 原设置表单与操作模式，接入实际配置；标签按钮去掉浏览器默认边框 | 已修正 |
| 列表与日志 | 保留表格、筛选、分页、自动刷新、错误提示 | 已验证 |
| 手机页面 | 工具卡片换行，指标纵向显示，宽表在自身容器内滚动 | 无页面横向溢出 |
| 文字和数据 | 导航、标题和操作均来自当前管理需求；数量读取真实台账，缺失显示未就绪 | 无虚构统计或旧业务标题 |

保留的业务差异：原人格、表情包和模型服务管理被替换为下载、上传、监听、项目文件和本地模拟。未复用旧后端、认证数据或聊天数据库。

## 操作验证

浏览器已访问三个配置页、搜索下载文件、查看日志，并实际提交“模拟完整流程”，等待其成功状态；模拟执行真实本地落盘、台账、PCF解析、简报及模拟Codex查询，未登录平台、上传NAS或发送微信。页面无JavaScript错误或框架错误覆盖层。

后端10项测试通过，覆盖只读状态、当前文件版本、路径范围、SQL参数、配置校验/冲突、原工具配置校验器、子进程与重复任务、API会话及跨站请求防护。codex-wechat全套40项测试通过，包含新增的安全停止入口。前端生产构建通过。

正式下载、SMB传输与真实微信发送沿用原工具入口，未在此次界面验证中执行。

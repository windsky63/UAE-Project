# 2026-10-31 整个项目覆盖更新

适用于已有 Python 3.12 环境的服务器。包含管理中心、FusionLive 同步工具、微信工具、绿联云上传工具的完整程序，以及各组件发布清单。

1. 安全退出管理中心及同步、微信、上传和后台解析任务，等待进程完全退出。
2. 解压压缩包，将包内所有文件夹、文件合并覆盖到 `D:\阿联酋项目`。
   解压后必须能看到 `D:\阿联酋项目\FusionLive同步工具\release_manifest.json`，该文件与 `main.py` 同层。
   不要覆盖到 `FusionLive同步工具` 子目录内，也不要多套一层压缩包名称目录。
3. 运行 `FusionLive同步工具\maintenance\检查程序完整性.cmd`。校验通过后，用原入口启动管理中心及同步。

无需备份原程序文件，无需删除原目录，无需重装已有依赖。本包不带数据库、下载、日志和解析缓存；合并覆盖后，服务器现有运行数据仍在原位置。包中不含服务器正在使用的微信配置、NAS配置或管理中心网络配置，不会替换这些配置。

本次修复：FusionLive所有HTTP请求的连接、HTTPS握手和读取超时统一设为90秒，覆盖登录、目录、清单、关联、下载、注销及注销确认。完整程序包包含配套完整性清单。90秒是各阶段等待上限，不是整个文件的下载总时限。

同步基础发布版本仍显示 `2026.10.30-extraction-cache.1`，补丁标识为 `2026.10.31-all-http-timeout90.1`，属于正常情况。

此包没有修改启动检查的120秒时限。服务器此前曾在台账完整性检查阶段超时；如果再次发生，应保留 `scheduler.log` 排查，单独完整性检查通过不代表自动启动一定能在120秒内完成。

这是包含 FusionLive 登录配置的私有部署包，仅用于自己的服务器。

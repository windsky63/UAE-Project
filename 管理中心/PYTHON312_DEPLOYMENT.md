部署包位于 `管理中心/releases`；各工具独立包使用各自 `releases`。`exports` 是业务导出数据目录，应保留，不随本机部署包复制或清空。

本包使用服务器已安装的 Windows Python 3.12，不包含 python-runtime、.venv-analysis 或 codex-wechat/.venv。已包含构建好的网页，无需安装 Node.js 或重新构建前端。

1. 先解压到独立暂存目录。停止旧管理中心和业务工具，备份服务器现有配置、下载文件、台账、日志和聊天记录。
2. 将程序合并到最终部署目录；保留服务器已有的上传 config.json、微信 wechat.codex.json、同步 app/local_credentials.py、网络配置、自定义规则、模板以及各目录 runtime、downloads、logs、data、exports 中的业务数据。首次配置默认开启Codex回复及发送，数据库目录为D:/xwechat_files、账号为；空会话启动进入待配置模式。不要覆盖服务器已有同名配置。包内含项目现有同步登录凭据，仅用于本项目私有服务器，不公开分发。
3. 在最终部署目录双击 `install_python312.cmd`。安装时需要联网下载依赖，使用服务器的 Python 3.12 创建根目录共享虚拟环境 .venv-analysis，将全部工具依赖安装到该环境，并检查依赖和必要模块。Python 安装需包含 pip、venv 和 Tcl/Tk。也可明确运行 `C:\服务器Python312路径\python.exe setup_python312.py`。
4. 如果已有虚拟环境使用 Python 3.14 或其他版本，安装入口会停止并提示。停止相关工具后，将旧环境目录改名备份，再运行安装；不要混合覆盖环境。脚本不改业务配置，不启动下载、上传或微信监听。
5. 本机运行 `打开管理中心.cmd`；局域网运行 `打开管理中心-局域网.cmd`，其他电脑直接访问 `http://服务器IP:8765/`，无需会话链接或主机名白名单，不生成访问地址.txt。

已有正常的 Python 3.12 共享环境时，可在项目根目录执行 `.\.venv-analysis\Scripts\python.exe -m pip install -r requirements.txt` 补齐全部依赖，然后重启管理中心和微信监听。管理中心配置校验、同步、上传、微信及其独立启动入口均只使用 `.venv-analysis`；旧 codex-wechat/.venv 保留但不再使用。缺少共享环境时会提示安装，不再回退到其他 Python。

若旧版安装时出现 requirements.txt 的 GBK/cp936 解码错误，替换新版根目录 setup_python312.py 与 requirements.txt 后重新运行安装入口；无需删除虚拟环境。新版在隔离模式下显式指定 `-X utf8`，并为依赖清单声明 UTF-8。手动补装也可用 `.\.venv-analysis\Scripts\python.exe -X utf8 -m pip install -r requirements.txt`。

本版本修复了 Codex elevated Windows 沙箱创建线程时的根路径读取权限冲突；Windows 可读取项目外文件，写入范围仍按只读/编辑模式约束，沙箱网络禁用。Codex CLI 和登录、微信客户端与账号、NAS 访问配置需在服务器上自行准备，不复制开发机认证缓存。

共享连接方式和目录列表在“微信与 Codex → 配置设置”编辑，默认自动发现 codex-wechat 的同级目录，可关闭自动发现后手动修改。网页对话默认继承共享连接方式，也可单独覆盖；共享配置对网页下一轮生效，微信监听需重启。WebSocket 受阻时选择“HTTPS 流式（跳过 WebSocket）”。普通重连只显示连接状态。群任务等待时提示排队，轮到处理时才提示思考；提示及回答带任务编号，预览不发送。未选择独立来源的聊天会从共享目录自动发现同步台账；保留服务器已有账号与聊天配置，并核对目录列表。目录配置不修改 Windows ACL。

旧进程若安全停止无响应，先用 `.\.venv-analysis\Scripts\python.exe -B .\管理中心\diagnose_shutdown.py` 检查当前锁和进程，确认原任务已退出后再覆盖。新版停止日志每30秒显示等待对象和耗时，简报线程未结束时记录调用堆栈；它不会强杀任务，也不能保证消除尚未查明的内部阻塞。

微信后端默认使用常驻 App Server（`codex_backend=app-server`），每群/私聊复用一个会话，默认 55% 上下文时预建、70% 时完成当前回复后轮换，可在页面调整。供应商未报告窗口大小时可手动填写用于比例判断；缺少数据时默认 20 轮保守轮换。重启后用本地摘要衔接新会话，不保存跨进程的模型工具历史。升级时需同步更新整个 `codex-wechat/wechat_local` 包及管理中心网页产物。旧版或自定义 CLI 不支持协议时，可选择 `exec` 兼容模式。默认不对失败生成自动重试，也不在失败后自动降级重放；保存配置后安全重启监听。

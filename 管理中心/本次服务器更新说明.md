服务器更新说明（2026-11-14）

本包为完整程序部署包，包含管理中心、已构建网页和全部 tools 程序，不包含本机业务数据库、下载资料、运行日志或 Python 虚拟环境。

本次主要更新：

- 新增图纸文件变更简报：文件数、新增、更新、移动/更名、删除/不可见；负责范围按单元及专业展示，其他合并一行，未识别一行。
- 微信发送：在原有每个接收会话的“推送文、管道简报”旁增加“图纸简报”选项。两类简报共用原有简报发送时间，不额外配置接收群或时间。升级后图纸简报在各会话默认不勾选，请在配置设置中明确勾选需要接收的群。允许某群仅管道、某群仅图纸，或同时发送。
- 正式简报生成时将两类图片保存为同一不可变发布快照，发送时按会话配置筛选。图纸简报使用独立图片编号记录投递，支持手动仅发送图纸简报、失败重试和重复发送防护；模拟示例不发送。每日推送页可预览两类图片。旧快照没有图纸图片时会提示重新生成，不用旧图代替。
- 负责范围统一由管理中心/config/drawing_scope.json 保存，Ima 和图纸简报共同读取。下载工具配置设置和 Ima 同步配置均可编辑同一配置。
- 初始负责专业为管道、钢结构、安全、消防及火气设备；单元为027、037、038、039、213、265、273，不限定厂区。

更新步骤：

1. 在服务器安全停止下载、解析、Ima、微信等业务进程，再关闭管理中心，备份现有程序和数据。
2. 将压缩包解压到独立暂存目录，按现有“管理中心 + tools”目录结构合并程序到服务器项目根目录。若服务器仍是旧的根目录工具布局，先按根目录 README 核对业务数据位置，不直接混合目录。
3. 保留服务器 runtime、downloads、history、exports、logs、data、待同步及 .venv-analysis。保留服务器已有的微信、NAS、网络和其他实际运行配置。同步登录文件按项目既有打包规则随包覆盖；包内若有 Ima 一次性凭据 bootstrap，也按既有机制导入。本包含私有服务器凭据，请勿公开分享。
4. 首次使用共享负责范围时复制包内 管理中心/config/drawing_scope.json。若服务器已配置此文件，保留服务器版本，避免覆盖后续人工修改。
5. 根目录运行“验证程序完整性.cmd”，再启动“打开管理中心.cmd”，刷新浏览器；进入下载工具配置设置或 Ima 同步配置核对负责范围。
6. 独立预览入口：tools/FusionLive同步工具/生成图纸变更简报.cmd，生成的预览不自动发送。微信正式发布使用原“生成管道简报/生成最新管道简报”入口，会同时准备图纸简报图片，再在每日推送页核对会话和内容后确认推送，或由常驻调度按原发送时间发布。模拟示例加 --demo，不发送。

文件数是当前本地台账有效图纸数量，变更列为指定北京日期事件；删除/不可见不表示已确认删除。旧简报需重新生成，新负责范围不会自动改写已有简报。

共享配置当前随完整部署清单校验；若保留的服务器负责范围与包内默认值不同，或保存后修改配置，完整性检查可能仅对此配置报告内容不一致，请核对差异。不要为消除这一提示覆盖已确认的服务器负责范围。

# 项目检查与完善记录

本轮检查范围：管理中心、FusionLive同步工具、资料解析及管理工具、codex-wechat、Ima知识库管理、绿联云上传工具，以及部署完整性流程。

## 本轮修复

1. 图纸发送的时间窗口跨过午夜时，使用前一日计划时间计算窗口和当天尝试记录，避免漏发或重复检查。
2. 图纸发送进程中断后的记录恢复提前执行，即使当前不在发送窗口也会将未确认记录标成待核对；不自动重发已提交或不确定的文件。
3. 首次启用图纸发送严格限定为建立基线，后端拒绝隐藏的发送全部策略，与已确认的产品行为一致。
4. 解析调度锁无法读取时显示状态未知，避免把无法探测误报为外部运行中。
5. 独立解析启动命令缺少 --data-home 参数值时返回退出码2和明确提示，不输出异常堆栈；代码目录导入条件修正为检查代码目录自身。
6. 旧 JSON 和数据库中的完整解析结果增加结构校验；损坏结果不能被导入或标记完整。批量读取仍按提交版本核对，失败保留重试机会。
7. 清理移除汇总复用后留下的无用身份字典和逐文件缓存 stat 检查，保留对源文件的必要检查。
8. 刷新同步和NAS的组件清单及全项目完整性清单，使根目录验证命令覆盖本轮修改和新工具。

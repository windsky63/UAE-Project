# 工具独立部署与管理契约

每个工具的运行代码、默认规则和必要静态资源由自身携带。独立部署只需指定业务数据来源，不应为了读取台账而要求安装数据来源工具的代码。

## 两种运行模式

独立启动：未设置 PROJECT_MANAGER_HOME，使用自身实现、runtime配置及defaults中的默认规则。解析工具通过 --data-home 选择台账和文件目录。Ima与微信读取已授权数据源的SQLite/文件，而非导入同步工具代码。

管理中心启动：中心明确设置 PROJECT_MANAGER_HOME，并指定数据目录、配置、任务标识和操作。微信发送、共享图纸范围及Ima/微信的数据读取适配器绑定中心实现。服务缺失时报错，不能静默回退到工具内置实现。中心持有任务记录并通过既有锁及停止协议管理生命周期。

PROJECT_MANAGER_HOME是管理绑定，不通过“旁边存在管理中心目录”推断。数据目录暂留原路径是兼容现有业务数据，不能据此把该目录的代码当成依赖。

## 本轮落地

- 跨工具通用实现一致性检查移至管理中心测试，工具内部不承担兄弟工具一致性校验。
- Ima内置business_type、archive_index及编码规则；不再从同步工具目录导入它们。
- 微信文件检索内置同样的只读模块，导出的聊天技能也携带这些资源；Python wheel已包含必要文件。
- 中心提供同版资料读取模块，受管理时显式加载中心版本。
- 图纸范围在独立模式读工具runtime/drawing_scope.json，缺失时读工具defaults；受管理时读取绑定中心config/drawing_scope.json。
- 仅复制独立工具到临时目录后，解析工具、Ima及微信的导入和规则读取验证通过；另验证中心绑定及缺失时不回退。

现有测试仍覆盖数据源联动的业务场景；联动场景是集成测试，独立部署的运行依赖由隔离目录测试验证。后续迁移更多功能时按此契约逐项检查，不通过恢复旧转发入口解决依赖。

## 日志配置与定位

受管理进程复用中心 `shared_services/log_policy.py`，中心通过 `config/logging.json` 显式下发日志规则（不存在时采用 `config/logging.example.json`）；本机自定义配置不进入程序覆盖包或哈希清单；不根据相邻目录决定模式。修改规则后安全重启对应工具。独立工具均携带同版 `log_policy.py`，移走或重命名工具目录仍可写本地日志，管理绑定的公共服务缺失时会报错。

默认进度间隔 30 秒，空闲提示间隔 300 秒；阶段开始、结束、不同错误立即记录。同一会话的连续相同读取错误按间隔汇总次数，恢复时单独记录。开启 `detailed` 仅用于临时排查。每个日志文件默认 5 MiB，保留 4 份轮转副本；北京日期切换后新日志写入新日期目录，文件均为 UTF-8。该限制针对每个日志文件，历史日期仍可在日志页清理。

受管理主进程的输出由中心写入 `项目根目录/logs/YYYY-MM-DD/<工具ID>/日期-工具-操作-任务ID.log`，工具不重复写同一份输出。独立子进程（后台解析、简报生成、发布及注销守护）持续排空输出，并保存各自诊断，不依赖页面打开。独立工具的运行日志位于自己的 `logs/YYYY-MM-DD/<工具ID>/`（微信使用自定义状态目录时，日志跟随该本机状态位置）；解析工具指定 `--data-home` 时写入所选数据目录。解析日志统一归属 `analysis`，与同步下载日志 `sync` 区分。

- 同步：`scheduler.log`、`run.log`；独立桌面工具使用 `gui.log`，注销守护使用 `watchdog.log`。
- 解析：`scheduler.log`、`analysis.log`、`analysis-worker.log`、`cli-diagnostics.log`；简报生成过程保留在简报输出目录，发布子任务证据保留在 `runtime/publication_jobs/<任务>/worker.log`。
- NAS：`nas/run.log`；逐文件上传审计和轮次 JSON 摘要继续保留，不将逐文件成功信息全部刷入运行日志。
- IMA：`ima/run.log`，标准输出仍保留原有 JSON 协议；逐文件回执和每日记录是业务证据，不作为重复进度输出。
- 微信：`wechat/listener.log`，包含会话/任务标识、异常类型和必要堆栈，不记录完整聊天正文或生成回复作为常规运行日志。

日志页默认显示简短摘要，完整异常可展开；级别筛选及搜索仍检索原始完整事件。刷新最多读取最近 80 个文件，每文件最多尾部 256 KiB / 1500 行；文件名匹配优先，页面说明实际读取范围，避免把有限尾部结果说成全部历史。历史日志仍可读取，不自动转换或删除已有日志。

排障时先看任务退出码和异常摘要，再展开完整诊断，根据文件路径、阶段、任务 ID 和异常类型定位；进度心跳仅说明进程仍在等待或处理，不代表操作成功。密码、Token、Cookie、Authorization 及带密码 URL 在写入和展示前脱敏。
